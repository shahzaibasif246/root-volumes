# A basic python script I used to estimate root volumes from their areas  

This was an initial attempt at exploratory data analysis to reconstruct root volumes given their area determined via imaged cross-sections. This script is inefficient as it does not use the fact that the data is the spreadsheet is vectorized.  

Another script was made in R at a later date that was efficient and also simplified some of the calculations. This may be added at a later date.
